# desp_from_acc
Aplicación que recopila métodos del estado del arte para obtener desplazamiento con base en señales de aceleración. Se enfoca en análisis de estructuras como puentes o viaductos carreteros y ferrovoarios.

La aplicación de escritorio DESP Studio incluye diez métodos: siete de la tesis,
Bunce para puentes y trenes, la propuesta de superposición modal de Jorge Luis
Martínez Valencia y Tokunaga et al. (2022) para pasos de tren por vanos
simplemente apoyados. El método JM reproduce el cálculo de la última gráfica de
`easy_ama_jmpc` y permite inspeccionar sus etapas intermedias.
