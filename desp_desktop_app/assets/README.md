# Recursos locales

La aplicación funciona sin descargar recursos durante la ejecución. Este
directorio contiene únicamente fuentes redistribuibles para que la interfaz y
los informes conserven su tipografía en equipos Linux y Windows.

La interfaz utiliza una paleta y una tipografía comunes a las gráficas, los
controles y los informes.

| Recurso | Uso |
| --- | --- |
| `fonts/NotoSans-Regular.ttf` | Texto y controles de la interfaz. |
| `fonts/NotoSans-Bold.ttf` | Títulos y énfasis. |
| `fonts/LICENSE.txt` | Licencia de redistribución de Noto Sans. |
